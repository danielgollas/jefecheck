Installation Instructions

Windows XP (Vista tested but not officially supported)

Download the installer and run it to setup JefeCheck on your system.
If you are trying to use JefeCheck in Windows Vista, turning off the Aero Theme is highly recommended.
 
Mac OS X (10.4 and above, Intel Only)

Download the Mac Installation file (Intel Only).
Uncompress it and Drag and Drop the JefeCheck App into your Applications Folder
 
Linux (32 or 64bit)

Download the tar ball and read the instructions on how to install.
Installation usually only involves running the included script to install support files and plugins (they are installed to your home directory) and then putting the binary wherever you wantIf in doubt, ask your system administrator for help.
Tested on Open Suse 11.0, Ubuntu 8.04 and Fedora Core 10.

Aditional libraries that might be required on Linux

  • GFL Shared Libraries (Included in the installation package)
    Or Download and install the shared libraries in your Linux Computer    .
  • OpenSSL (at least v0.9.8). Should already be installed, but some distros might need an update.
