What is JefeCheck about anyway?

PLAY

  • Hardware Accelerated High Resolution RAM based
    image sequence playback.
  • Many, many formats (DPX, OpenEXR, TIFF, TGA, JPEG, BMP, etc)
  • Play up to four 2K streams at once on comodity hardware
  • 4K playback capable (hardware dependent)
  • Different viewport layouts (single, 2x2, side by side, top and bottom)
  • Real Time transformations (zoom, pan, flip, flop)
  • Once, Loop and Ping Pong playback modes.
  • DPX Metadata Display
  • Real Time Aspect Ratio modifications, with image deformation (for anamorphic) or cropping with black bars.
  • Automatic Proxy Generation
  • Area of Interest loading
  • Low hardware requirements
  • Fully multi-threaded

Process

  • Process image in Real Time and Full Resolution using gaming level hardware.
  • Easy to write plug-in system based on XML text files and the OpenGL Shading Language. Apply these and other FXs in Real Time
    • 1D and 3D LUTs
    • Brightness, Contrast and Saturation
    • Gamma Correction
    • Primary Color Correction
    • Difference Mattes
    • Pre-comps (mix, over, inside, green and blue chroma keys etc)
    • Anaglyph Stereo image creation.
    • Split screen in any angle and position.
  • FXs are stackable, apply as many as you want.
  • Flexible LUT format
    (if you can process an image with your LUT, then JefeCheck can use it)
  • Render to image sequences.

Share

  • Participate in JefeCheck Remote Sessions: playback and review sequences over a network or the Internet with as many participants as you want.
  • Control all aspects of the playback from any workstation in the session.
  • Apply any FX on any computer in the session, what you see is what everyone else sees.
  • Hold remote sessions between Windows, OS X and Linux workstations.
  • Secure: no image information travels over the network, frames must be synchronized on both computers beforehand.
  • Use remote pointers and text chat to communicate exactly what you want to all other participants.
