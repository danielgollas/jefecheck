Change log and bug fixes

  • JefeCheck 1.5.0 (released October 17th 2012)

    MAJOR CHANGES:

    • Fisrt Release in over two years! : We will try to keep adding new features and fix bugs.
    • JefeCheck is now Donationware!: You can use the current version of JefeCheck for free for any project, including commercial stuff. If you like it, please consider donating.
    • 64bit across the board: All JefeCheck builds are now 64bit on Windows, Linux and OSX

      Minor Changes:

    • Fixed FX loading error on ATI GPUs


  • JefeCheck 1.4.03 (released August 6th 2009)

    MAJOR CHANGES:

    • Brand New User Interface, no more shiny buttons! : The GUI is now simpler than ever, less clutter, more sober color scheme and easier to use.
    • Brand new Color Correction controls and Shortcuts: Common CC operations like LUT , Exposure, Gamma, Brightness, Contrast and Saturation are easier to apply than ever.
      Just press the shortcut key and drag on the screen to adjust.
    • Support for LUT cubes sizes 32x32x32 and up: Using the .cub format (Truelight Cubes)

      Minor Changes:

    • Better OpenEXR Support: Better handing of Display Window and Aspect Ratio attributes, better handling of Half values. Optional 16bit float to 8 bit Integer tone mapping.
    • Color Correction favorites: Save common Color Correction attributes to shortcut keys.
    • Improved Pipeline Integration: Use environment variables to define: Default Browse Path, FX Path, LUT Path and Default LUT. New command line argument to define LUT for each viewport.
    • Drag and Drop folders, first found image sequence will be loaded.
    • RGB filters now show channels in Grayscale, instead of in color.
    • Improved Playback performance
    • Improved color correction performance on lower end systems (Tested in the extreme case of MacBooks with integrated Intel GMA950 video cards).
    • Aspect Bars can now be semitransparent.
    • Better handling of Remote Session FX and LUT sharing.
    • Many small bugs squashed, more stable.

  • JefeCheck 1.3.704 (released May 21st 2009)

    MAJOR CHANGES:

    • Support for Linux 64 bit! The main advantage of this is that you can use more than 4GB of RAM to cache frames.
    • Playlists and Playlist Window.
    • Playlist Support in Remote Sessions. Among other things, loading from a playlist automatically loads the item for the other participants in the Remote Session.
      Participants must define their sequence search paths so JefeCheck knows where to look for remotely loaded sequences.
    • Histogram display.
    • FX Stack Favorites. They let you save and load commonly used FX Stacks with a single keystroke.
    • Updated FXs:

      • Updated the Chroma Key FXs, they now use a MUCH better algorithm and extract very nice mattes.
      • Split FX now shows a line at the split with configurable opacity and width.

    • NewFXs and LUTs:

      • Fun FX - Deforms the images in funny ways.
      • Log To Lin FX - Lets you apply a true Log To Lin transformation, without using LUTs, it's slow, but you can configure white point, black point, etc.
      • Convolution FX - Lets you apply a any 3x3 convolution kernel to the image. Comes with preset values for Sharpen, Blur, Gaussan Blur, Edge Detection and Emboss.
      • Add FX - Adds to images together
      • Multiply FX - Multiplies two images togheter
      • New log2LinsRGB 3D LUT.

    • New shortcuts:
      • F key now fits the image to the viewport
      • r, g, b, a now toggle the channels display.
      • Shift+drag on the viewport scrubs the timeline.
      • Shift+F1-F5 loads FX Stack Favorites, Ctrl+Shift+F1-F5 saves FX Stack Favorites.
      • i and o set the In and Out points in the timeline, Shift+i and Shift+o reset them.
      • Alt+i sets the In point, unloads the sequence and begins loading from that point on. Similar to alt clicking on the timeline.

    • New Command Line Options: Can now load sessions, playlists and FX Stacks, in addition to the previous options for loading sequences, scale and range control.
    • Vsync option fixes tearing issues in high motion sequences
    • New Online Store!

    MINOR CHANGES AND BUGFIXES:

    • Improved overall performance.
    • Faster DPX loading.
    • EXR Images loaded in the HALF format can now be loaded as 25% or 50% proxys.
    • Added the Balance Reads option, when enabled, JefeCheck tries to load all tracks at the same rate, even if some are big EXR files and others are small jpgs. This prevents small sized sequences from filling up RAM while big ones are still loading.
    • Fixed .avi file generation after rendering in Linux.
    • Streamlined the Licensing scheme. Now you simply buy online, and then request a License for your machine directly from JefeCheck.
    • Defining the area for Region of Interest (crop) loading is now more intuitive. Just drag the corners of the crop area to resize and drag the crop area to move.
    • Drag and Drop now works for FX Stack files, session files and Playlist files.
    • Some slider controls could not be set by typing in a value, now they can be.
    • Updated User Manual
    • Updated the Main Windows GUI a little bit.
    • Colored Pointers in Remote Sessions
    • FXs and LUTS are now loaded automatically from the installation folder, or from the path defined in the enviroment variables JEFECHECK_FX_PATH and JEFECHECK_LUT_PATH.
    • The default path used when browsing for files can be defined in the environment variable JEFECHECK_DEFAULT_BROWSE_PATH.
    • Added the System Requirements Check Window to determine what features are available on the hardware.
    • Ended support for Mac Power PC architecture. JefeCheck only runs on Intel Macs now.
    • Installation on Mac is now as simple as can be, just run!
    • If a frame is unreadable, you can skip it and continue loading the rest of the sequence.
    • Many bug fixes, some minor and some that caused crashes.

 

  • JefeCheck 1.1.370
    • CPU optimizations: Jefecheck no longer hogs the CPU. CPU usage goes down to 0% when paused and was dramatically reduced during playback and manipulation. Jefecheck now plays nicely with the rest of the programs you may have open at the time.
    • Start loading button for each sequence. You can start loading one sequence while you are still browsing for another sequence to load into another track. The start all button remains there if you want to start loading all sequences at the same time.
    • Fixed the arrow key shortcuts, they now work correctly to advance and rewind frames.
    • Redisigned FX Control Window is now less cluttered.
    • Most dialogs now have a milder contrast color scheme using white on gray instead of white on black.
    • Remote session colored pointers: During a remote session, your remote pointer can now be drawn in one of 8 fancy colors.
    • Brand new FXs!:

      • Gaussian Blur 3x3: Applies a 3x3 gaussian blur.
      • Average Blur 3x3: Applies a 3x3 average blur.
      • Average Blur: Applies an arbitrarily sized average blur. WARNING: This is a very resource intensive operation, we don't recommend setting the blur size to over 15 pixels, since it can cause a video driver crash.
      • Aspect bars: Applies aspect crop bars to the image. Since this is an FX, it can be rendered out and you can add aspect crop bars to your renders.
      • Move2D: Allows you to move the image within it's own frame. Can help when doing pre-composites.

    • DPX Loading improvements: Fixed some dpx loading issues that could cause a crash when memory ran out.
    • EXR Rendering to file: Fixed a rendering bug that caused a memory leak when rendering to OpenEXR files. OpenEXR rendering is now very stable.
    • Fixed a bunch of minor bugs including a crash that ocurred when applying a 3D LUT if only one LUT was loaded.
