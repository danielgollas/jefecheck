Quick Start User Manual Color & FX Build from Source

Quick Start

Get JefeCheck 2.0 running in minutes. Install a pre-built binary, load an image sequence or a movie, and start reviewing. In the shortcuts on this page, Ctrl means Cmd on macOS.

Install

macOS — install with Homebrew:

$ brew install --cask danielgollas/jefecheck/jefecheck

Windows — install with winget:

$ winget install danielgollas.JefeCheck

Linux and portable builds — download the latest archive from the GitHub Releases page (jefecheck-linux-x64.tar.gz, jefecheck-windows-x64.zip or jefecheck-macos-arm64.dmg). Extract it and run jefecheck. To build from source instead, see Build from Source.

Load your first sequence

Three ways to open a sequence or a movie:

  • Drag and drop — drag any frame of a sequence, or a movie file, onto the viewport. It loads into the first plate, and the full frame range is found from the neighbouring files. Hold Shift while dropping to load at 50%, or Shift+Ctrl for 25%.
  • Quick Load — press Ctrl+O (File > Quick Load…) and pick a file. It loads into the active plate straight away.
  • Load Sequence Manager — press Ctrl+L to set up all four tracks at once (range, scale, bit depth, channels, crop), then click Load All.

Quick color check

Hold a key and left-drag on the viewport: W Gamma, E Exposure, Q Brightness, D Contrast, S Saturation. Add Alt to change all plates. To apply a LUT, open the LUTs dock (F4), select a LUT and click Apply to active plate (or double-click it). Reset color with Shift+R.

Review with others

Open the Remote Session dock (F5). Host starts a session on your network, Cloud hosts one through JefeCheck Cloud and gives you a session code, and Join connects by code or by IP address. Playback, color and FX changes are mirrored to everyone. Each person plays their own copy of the media. See Remote sessions below.

User Manual

JefeCheck is built around a few ideas. Tracks (A–D) hold image sequences or movies. Plates are the up to four areas of the viewport that show them. Real-time changes — color correction, LUTs and GLSL effects — are applied by the GPU as frames are drawn. Source files on disk are never changed.

Interface overview

The main window has a menu bar, the viewport in the middle, and docks around it:

  • Menu bar — File · View · Window · Help.
  • Viewport — one, two or four plates, depending on the layout.
  • Docks — Plate Manager, Timeline, FX, LUTs, Notes, Playlist and Remote Session. Drag a dock by its title bar to move it, stack it as a tab, or float it as its own window. Toggle each one from the Window menu.
  • Status bar — messages and the current layout. Toggle it with View > Show Status Bar.

Ctrl+Alt+F (Window > Hide Controls) hides the menu bar, docks and status bar for a clean display. Press it again to bring them back.

Loading media

JefeCheck reads DPX, OpenEXR (including multi-layer files), JPEG, PNG, TIFF, TGA and BMP through OpenImageIO, plus .mov, .mp4 and .mxf movies.

  • Quick Load (Ctrl+O) and drag and drop load straight into a plate. Quick Load uses the active plate; a drop on the viewport uses the first plate. Drop with Shift for 50% or Shift+Ctrl for 25%. New loads use the default bit depth and decode filter from Preferences.
  • Load Sequence Manager (Ctrl+L, File > Load Sequence Manager…) has one strip per track. While it is open, each plate shows a preview frame of its track, and files dropped on the viewport go into the manager instead of loading.

Each track strip in the Load Sequence Manager has:

  • Browse… / Recent — pick a file of the sequence, or a recently used one.
  • From / To — load only part of the range. Numbers match the frame numbers in the file names.
  • Scale — load at 100%, 50% or 25% as a proxy.
  • Bit — in-memory format: 8-bit, 16-bit or 16-half (half float). Higher depths keep more precision under heavy color work and use more memory.
  • Ch — for multi-layer EXR files, the channel set to load.
  • Crop — load only a rectangle of the image to save memory.
  • Reload and Unload & Clear — read the track from disk again, or unload it and clear its fields.

The strip also shows an estimate of the track's size. Click Load All to close the manager and load every track that has a file.

Movies and sound

Movies (.mov, .mp4, .mxf; ProRes 422/HQ/4444/XQ, H.264, H.265 and DNxHR) load like a sequence. A movie is one track. Range, scale, bit depth, crop, hold, offset and notes work the same way, and the timeline counts its frames from 1. Frames are decoded into memory, never extracted to disk. Numbers in a movie's file name are never read as frame numbers.

  • Frame rate — loading a movie sets the player to the movie's exact rate (for example 23.976). If you load several, the last one wins.
  • Color — YUV is converted with the file's own matrix and range. Untagged files are treated as Rec.709 video range.
  • Sound — every track with audio plays, mixed. Mute a track with the speaker on its timeline lane, or from the lane's right-click menu. Mute is saved with the session. Reverse playback is silent.
  • Hardware decoding — Preferences > General > Hardware decoding (Auto / Off). Auto uses the graphics hardware when it can and falls back to software.

Memory and long clips

You don't have to fit a whole clip in memory. Frames load ahead of the playhead and frames behind it are unloaded to make room. Click anywhere on the timeline and JefeCheck loads around that frame. The green segments under each timeline lane show the frames in memory right now. Preferences > General sets the Memory limit (% of RAM) (default 90%) and what happens When loading can't keep up: keep time and skip frames, or show every frame and slow down. Automatic keeps time for clips with sound and shows every frame for clips without.

Playback and the timeline

The Timeline dock (F8) holds the transport controls and one lane per track.

  • Transport — rewind to start, step back, play / pause, step forward, fast forward to end.
  • Loop mode — Once, Loop or Bounce (keys 8 / 9 / 0).
  • F / In / Out — the current frame and the In and Out points. Set them from the keyboard with I / O; Shift+I / Shift+O reset them to the timeline start / end.
  • FPS — the target playback rate. A thumbnails toggle shows frame thumbnails on the lanes.

On a track lane, drag left or right to offset the track in time, Alt-click to load from that frame, and drop a file to load it into that track. Right-click a lane for Hold last frame, Set offset…, Mute audio (movies with sound) and Show frame thumbnails.

Plates and layouts

Four layouts: single (Ctrl+1), side by side (Ctrl+2), top and bottom (Ctrl+3) and 2×2 (Ctrl+4). Click a plate to make it active. The Plate Manager dock (F2) has one card per plate with:

  • Track and Layer — which track the plate shows, and which image layer drives it.
  • Aspect — source, 16:9, 4:3, 2.39:1, 2.35:1, 1.85:1, 1.37:1 or a ratio you type. Turn on Letterbox to mask the image with bars instead of squeezing it.
  • Flip / Flop and an RGBA button that cycles the channel display.
  • Transform — zoom, pan and rotation.
  • Color — LUT, gamma, exposure, contrast, brightness and saturation.

View > Plate Manager Shows chooses whether the dock shows the active plate, the visible plates or all four. Its layout follows the dock's shape: a row when docked wide, a column when docked tall.

The text overlay (T) cycles through off, basic info (frame, time, FPS, file name, resolution) and basic info plus DPX / EXR / EXIF metadata. Ctrl+H shows an RGB histogram over the plate.

Notes and review

The Notes dock (F7) lists the review rounds and notes on the active plate's footage. Click a note to jump to its frame.

  • Tools — Freehand, Arrow, Box and Text, with a colour and a size. Pick a tool, then left-drag on the plate. Esc puts the tool down.
  • Rounds — Lock Round freezes a round's notes. Click again to reopen it.
  • Show / hide — N (View > Show Notes).
  • File > Stamp Notes into EXR… — writes a copy of the active frame's EXR with its notes attached.
  • File > Export Review Summary… — writes every note in the session (media → round → frame) as PDF, TXT or CSV. The PDF includes thumbnails.
  • File > Export Review Package… / Open Review Package… — bundles the session, notes, custom LUTs and, optionally, the media into one .jcreview file. Opening a package relinks media that has moved (by file name under the search paths, or by fingerprint if you turn that on in Preferences) and merges its notes with yours without removing any.

Playlists

The Playlist dock (F9) holds a list of items. Each item is a snapshot of a multi-track setup.

  • Add Current snapshots the tracks you have loaded now. Add Files… builds an item from one or more files.
  • Double-click an item or press Enter to load it. Delete removes it. Shift+↑ / Shift+↓ reorder.
  • Each item has collapsible cards per track. Compact and Full paths change how much they show.
  • Scale override loads every track of an item at one scale.
  • Auto-advance plays each item once and moves to the next. Loop playlist wraps at the end.
  • Drop a .jpl file to replace the list, drop media on a card to add tracks to that item, or drop it on empty space to add a new item.

Save the list to a .jpl file. Open one with File > Open Playlist… or from File > Recent Playlists. In a remote session, media is loaded for everyone only through the playlist.

Sessions

File > Save Session (Ctrl+S), Save Session As…, Open Session… (Ctrl+Shift+O) and Recent Sessions save and restore the loaded tracks, plates and settings. A crash-recovery session can be turned on in Preferences.

Menus

File — Quick Load… (Ctrl+O), Load Sequence Manager… (Ctrl+L), Save Session (Ctrl+S), Save Session As…, Open Session… (Ctrl+Shift+O), Recent Sessions, Open Playlist…, Recent Playlists, Stamp Notes into EXR…, Export Review Summary…, Export Review Package…, Open Review Package…, Preferences… (Ctrl+P or Ctrl+,), Quit.

View — Fullscreen (F11), Show Histogram (Ctrl+H) and Show Histogram (All Plates) (Ctrl+Alt+H), Show Notes (N), Show Status Bar, Plate Manager Shows ▸ Active / Visible / All, Color Correction Favorites, Fit to Screen (F), Flip Vertical (V), Flop Horizontal (M), Text Overlay Mode (T), Reset Plate (Ctrl+R), Reset Color Correction (Shift+R).

Remote sessions

A remote session links two or more copies of JefeCheck. Media is never sent: each person loads their own copy. Playback, scrubbing, color correction, plate transforms and FX changes are mirrored to everyone. LUTs and FX that a joiner is missing are sent to them. Open the Remote Session dock with F5 (Window > Remote Session…). Set your nickname in Preferences > Remote. The dock has three modes:

  • Host — start a session on your network. Enter a session name, a port and an optional password, then click Start hosting. Others join with your IP address and port.
  • Cloud — host through JefeCheck Cloud. Sign in, pick a session group, name the session and click Host on JefeCheck Cloud. You get a session code (JEFE-XXXX) to copy and share. Session settings: ask before letting each person in (you then Admit or Deny each one), password, idle timeout and maximum number of people. The coordinator address is set in Preferences > Remote > JefeCheck Cloud.
  • Join — enter your nickname, then join with a Session code or an IP address (server, port and password), and click Join.

The dock shows the connection status, the people in the session, a chat log and a connection log. Leave ends your part in the session.

Chat: type in the dock's chat field, or press Enter on the viewport while connected, type, and press Enter to send. Esc cancels. Messages appear over the viewport and fade; Preferences > Remote sets the fade, background, size and number of lines.

Remote pointer: Shift + left-drag on a plate shows your pointer, with your nickname, to everyone. It points at the same image pixel for everyone, whatever their scale or screen.

Render and export

Window > Render… (F6) renders a plate's frame range with its color correction, LUT and FX applied.

  • Stills — JPEG, PNG, TIFF, TGA, BMP or EXR, with per-format options: JPEG quality, progressive and subsampling, PNG compression, TIFF and EXR compression, EXR depth, and 8- or 16-bit PNG / TIFF.
  • Video — H.264 (MP4), H.265 (MP4) or ProRes (MOV), with quality (CRF) or bitrate and an encoder preset. Video is encoded with the FFmpeg command-line tool bundled with JefeCheck. Exported video has no sound.
  • Resolution — source, 75%, 50%, 25% or a custom size.
  • Bake aspect / crop bars and Burn in notes — burn the letterbox or the plate's notes into the output. Both are off by default.

The render shows a progress bar and can be cancelled. When it finishes, a Show in folder link opens the output.

Preferences

File > Preferences… (Ctrl+P) has five sections. Changes preview live; Cancel puts everything back.

  • General — background color and checkerboard, default browse folder, start in fullscreen, open the Load window at startup, crash-recovery session, aspect bar opacity, timeline thumbnails, feedback messages, and the Playback & Engine settings: memory limit, when loading can't keep up, OIIO decode threads, hardware decoding, default decode filter (nearest, triangle, mitchell, lanczos3) and default bit depth.
  • Text — overlay text size, color, hinting, filter, gamma and shadow, with a live preview.
  • Formats — EXR: ignore display window, ignore header aspect ratio; read straight (unassociated) alpha; apply embedded orientation.
  • Search Paths — folders to search for media that has moved, optionally recursive, and whether to also match moved media by fingerprint (slower; off by default).
  • Remote — nickname, JefeCheck Cloud coordinator, chat appearance and remote pointer fade and color.

Color & FX

JefeCheck changes images in two places. Load-time settings (scale, crop, bit depth) are fixed when a track loads. Real-time changes (color correction, LUTs, GLSL effects) are applied by the GPU as frames are drawn and can be changed at any time. Nothing touches the files on disk.

Color correction

Each plate has gamma, exposure, brightness, contrast and saturation, set in the Color section of its Plate Manager card or by holding a key and left-dragging on the viewport:

  • W + drag — Gamma
  • E + drag — Exposure
  • Q + drag — Brightness
  • D + drag — Contrast
  • S + drag — Saturation

Add Alt to change every plate. Reset the active plate with Shift+R, or all plates with Shift+Alt+R. View > Color Correction Favorites saves the active plate's correction to one of five slots and loads it onto another plate later.

LUTs

LUTs in the FX folder load at startup. Drop more .lut, .cube or .cub files onto the LUTs dock (F4) to load them. The list shows each LUT's name, type, size and depth. Select one and click Apply to active plate, or double-click it. You can also pick a LUT from the Color section of a plate card. Refresh rescans the LUT folders.

Turn on Preview to inspect a LUT: a 1D LUT plots as a curve (input on X, output on Y); a 3D LUT shows as a color cube. A deformed cube means a color change; a straight line means desaturation.

Supported LUT formats

Format Type Notes
.lut1D — JefeCheck formatPlain text: header, entry count, then normalized values (0.0–1.0)
.cub / .cube3D — Truelight cubeText files in Truelight Cube v2.0 format
.tga3D — image LUTA 64×64 image that encodes a 16³ cube (for example the included UnitCube). Other image sizes, such as Nuke's 448×448 export, are not supported.

The FX panel

JefeCheck has a GLSL plug-in system for real-time effects. Every FX in the FX folder loads at startup. The FX dock (F3) shows the effect stack of the active plate:

  1. Add an effect — click + Add FX and pick one from its menu, sorted by category.
  2. Adjust it — each effect is a card with its own controls (sliders, knobs, fields, checkboxes and pickers). A control's label turns orange when it differs from its default. Click its reset dot, or right-click and choose Reset to default.
  3. Arrange the stack — effects run top to bottom; each one's output feeds the next. Drag a card's handle to reorder. Use the power button to turn an effect off without removing it, the chevron to collapse the card, and the remove button to delete it.

Each plate has its own FX stack. Stacks are saved with sessions and playlists.

Included FX

  • Color — 1D LUT, 3D LUT, Brightness/Contrast/Saturation, Channel, Gamma, Log to Lin, Primary Color Correction.
  • Comp — Add, Alpha Over, Chroma Key (Blue), Chroma Key (Green), Difference Matte, Flip Horizontal, Inside, Mix, move2D, Multiply, Ondita, Over, Split, Stereo SxS Squeeze, Subtract.
  • Special — Anaglyph BW Stereo, Anaglyph Color Stereo, Side By Side Anaglyph Color Stereo, Aspect Bars, Average Blur, Average Blur 3x3, Gaussian Blur 3x3, Convolution 3x3, Fields, OpenEXR.
  • Transitions — Fade, Radial.
  • Fun — Fun.

Writing your own FX (.jfx)

Each FX is a set of files in the FX folder:

  • plugin.jfx — XML descriptor: name, menu path (menuName="Comp/Mix"), author, controls and shader file names.
  • plugin.frag — GLSL fragment shader. Declare a uniform for each control's varName and write the result to gl_FragColor. Textures are sampler2DRect, so coordinates are in pixels, not 0–1.
  • plugin.vert — GLSL vertex shader. Most FX use the shared fixed.vert.

Control types in the descriptor: float, bool, texture (Track A–D or the previous FX's output), cube (3D LUT), lut (1D LUT), choice, newLine and spacer. A float can set style to slider, knob or field, and softMinimum / softMaximum for the range its control shows.

JefeCheck also sets these uniforms if your shader declares them: currentFrame, targetFPS, timestep, texCoord0–texCoord3, and <varName>_size for each texture. Start from MIX.jfx / MIX.frag or OVER.jfx in the FX folder.

Build from Source

JefeCheck is free software under the GNU GPL, version 2 or later. It builds with CMake and C++20 on all platforms. JefeCheck 2.0 lives on the qt-experimental branch.

It needs Qt 6 (Widgets, OpenGL and Multimedia), OpenImageIO, OpenEXR / Imath, FreeType, libcurl, zlib and the FFmpeg libraries (libavformat, libavcodec, libavutil, libswresample, libswscale; FFmpeg 6.1 or newer). CMake also downloads libdatachannel for remote sessions (-DJEFECHECK_WEBRTC=OFF skips it) and a static ffmpeg tool for video export (-DJEFECHECK_BUNDLE_FFMPEG=OFF skips it). If you'd rather not build, download a binary from the GitHub Releases page.

macOS

Tested on Apple Silicon (ARM64). OpenGL runs on Apple's Metal translation layer: deprecated by Apple, but it works. Retina displays are supported.

# Install dependencies with Homebrew
$ brew install qt openimageio openexr curl zlib cmake freetype ffmpeg
# Clone and build
$ git clone -b qt-experimental https://github.com/danielgollas/jefecheck.git
$ cd jefecheck
$ cmake -B build && cmake --build build

Runtime resources

JefeCheck finds its FX, LUTs and fonts in its application data folder. For a development build, link them from the source tree in the folder you run it from:

$ ln -sf $(pwd)/src/FX FX
$ ln -sf $(pwd)/src/fonts fonts

Release builds package src/FX/ and src/fonts/ with the binary.

CI and pre-built binaries
