Quick Start

Install with your platform's package manager, launch JefeCheck, then drag an image sequence or movie onto the window. The frame range is detected automatically and cached for real-time scrubbing.

$ brew install --cask danielgollas/jefecheck/jefecheck
$ jefecheck /path/to/shot.[1001-1096].exr

Press Space to play, [ ] to set the loop range, and F to fit the frame to the viewport.

User Manual

The interface is built around three regions: the viewport, the transport bar, and dockable inspector panels. All panels can be torn off, stacked, or hidden — your layout is remembered per project.

Playback & transport

  • Scrub by dragging the timeline or using the ← / → keys.
  • JefeCheck targets real-time playback — up to 4K sequences at 24 fps on consumer hardware — and scrubs with audio.
  • Toggle ping-pong, loop, or play-once from the transport bar.

Channels & comparison

Isolate the R, G, B, or alpha channels and apply RGBA masks on the fly. Load several sequences into separate tracks to compare, wipe, or stack them side by side.

Color & FX

Adjust color non-destructively as you watch. Apply 1D or 3D LUTs and log-to-lin conversions on the fly, or build your own real-time effects in the GLSL FX Stack — pre-comps, chromakeys, and stereo / anaglyph composites included.

$ jefecheck --lut /luts/show_rec709.cube shot.[1001-1096].exr
  • 1D / 3D LUTs and log-to-lin applied live — no re-render.
  • RGBA masks and channel isolation for quick checks.
  • GLSL FX Stack — author effects, save them to disk, reuse them.

Build from Source

JefeCheck is free software under GPL v2. Clone the repository and follow the platform build steps documented in the source:

$ git clone https://github.com/danielgollas/jefecheck.git
$ cd jefecheck
# see BUILDING.md for platform build steps

Build instructions and dependencies live in BUILDING.md. Contributions are welcome.
