Quick Start

Get JefeCheck running in minutes. Install a pre-built binary for your platform, load any image sequence, and start scrubbing.

Install

macOS — install via Homebrew cask:

$ brew install --cask danielgollas/jefecheck/jefecheck

Linux & Windows — download the latest pre-built archive from the GitHub Releases page (jefecheck-linux-x64.tar.gz / jefecheck-windows-x64.zip). Extract and run the jefecheck binary. To build from source instead, see Build from Source.

Load your first sequence

Three ways to open a sequence:

  • Command line — pass any frame; the full range is detected automatically from adjacent files:
$ jefecheck /path/shot.1001.exr
# explicit range notation also works
$ jefecheck /path/shot.[1001-1096].exr
  • Drag and drop — drag any frame (or a folder) from your file browser onto the viewport. The sequence loads into whichever track is assigned to that viewport. Hold Shift while dragging to load at 50% resolution as a proxy.
  • Load Window — press Ctrl+L, click Browse for a track, select any frame from the sequence, then click Start.

Scrub the timeline by clicking and dragging on the viewport while holding Shift. Zoom with the mouse wheel; pan by left-click drag.

Viewport layouts

Switch layouts with Ctrl+1 through Ctrl+4: single, two side-by-side, two stacked, or four-up. Press 1–4 to assign Tracks A–D to the active viewport, or Up / Down to cycle through tracks.

Quick color check

Hold a key and drag on the viewport to adjust on the fly — W Gamma, E Exposure, Q Brightness, D Contrast, S Saturation. To load and apply a LUT: open the LUT Manager (F4), browse and select a file, then pick it from the viewport's LUT list. Reset color corrections with Shift+R.

Start or join a remote session

Open the Remote Session Manager (F5): to host, fill in a server name, port (32000+ recommended), optional password, then click Start and share your IP and port. To join, enter the server IP, port, password (if any), and a nickname, then click Connect. Everything — playback, FXs, viewport transforms — is mirrored to all participants in real time.

For full reference on loading options, FX stacks, LUT formats, custom plug-ins, and collaboration, read the sections below.

User Manual

JefeCheck is built around three concepts: Tracks hold image sequences, Viewports display them, and Real-Time Modifications (color, LUTs, GLSL FX) are applied by the GPU on the fly without touching source files. Up to four tracks (A–D) can be loaded simultaneously and watched on up to four viewports in configurable layouts.

Interface overview

Opening JefeCheck shows the Main Window with the Load Window floating on top. The Main Window has three areas:

  • Menu Bar — access all windows, display settings, and help.
  • Viewports Area — where image sequences are rendered. Splits into 1, 2, or 4 viewports depending on the chosen layout.
  • Control Bar — timeline, track controls, playback controls, and per-viewport settings.

Hide the Menu and Control Bars for a clean display with Ctrl+Alt+F; press again to restore. The Load Window opens automatically on startup (configurable in Preferences).

Loading sequences

The Load Window (Ctrl+L) has one section per track. Key load-time options — these are baked into the track and cannot be changed without reloading:

  • Range — drag In/Out sliders to load only a subset. Numbers match the filename frame numbers.
  • Scale — load at 100%, 50%, 25%, or any value as a proxy. Linear resampling is faster; Bilinear is smoother.
  • Crop — enable the checkbox and drag the crop region in the preview to load only a rectangular sub-region, saving RAM. No real-time counterpart.
  • BitDepth — choose the in-memory format for loaded frames:
    • 8bpc — 8 bits/channel; the default. Good balance of memory use and image quality for standard display.
    • 16bpc — 16-bit integer per channel (0–65535), stored as float16 on the GPU; roughly double the RAM of 8bpc, and reduces banding under heavy color processing.
    • HALF — a 16-bit half-float option. With the current OpenImageIO backend it behaves the same as 16bpc (frames are read as 16-bit integer); the native half-float EXR path is not compiled in this build. Prefer 16bpc.
    • 4bpc — 4 bits/channel; ~2× more frames in memory at the cost of serious banding and color inaccuracies — useful only for checking black or missing frames.
    • S3TC — GPU texture compression; up to ~8× more frames in memory; small compression artifacts; not suitable for pixel-accurate quality checking.
  • Channels — for multi-channel EXR files, choose which channel set to load (e.g., Diffuse, Specular, Depth, RGBA).

Click Start to begin loading a single track, or Start All to load all configured tracks simultaneously. Cancel any in-progress load with the red X button next to the track in the Control Bar.

To reload from a specific point: Alt+Left Click on the timeline to restart all tracks, or on a specific track bar to restart only that track. Press Alt+I to set the In point and begin reloading from there.

Playback & transport

The Control Bar timeline shows all four track bars alongside the scrub knob. The SMPTE Counter shows elapsed time as HH:MM:SS:FF from the timeline start.

Loop modes — Once (plays and stops on last frame), Loop (repeats forward), Swing (plays back and forth) — are toggled with 8 / 9 / 0.

Set In/Out points with i / o (or drag the markers on the timeline); reset with Shift+I / Shift+O. The Loop Priority control determines when multiple tracks of different lengths loop: Shortest, Longest, or match the Timeline range.

The Track Options button (right-click on a track bar) gives access to Frame Offset (shift a track in time relative to the timeline), Hold Frame (None / Current / Edge when the timeline is outside the loaded range), and Unload Track. You can also drag the track bar left or right to change the offset interactively.

Viewports & layouts

Four layouts are available from the Control Bar or View > Viewport Layout:

  • 1×1 (Ctrl+1) — single full-window viewport.
  • 2×1 (Ctrl+2) — two viewports side by side.
  • 1×2 (Ctrl+3) — two viewports stacked vertically.
  • 2×2 (Ctrl+4) — four viewports.

Each viewport independently controls: Track Assignment (A–D, keys 1–4); Aspect Ratio (original, 4:3, 16:9, 2.39:1, 2.35:1, 1.85:1, 1.37:1, or any custom typed ratio); Crop Bars (mask the letterbox area rather than squashing the image); Flip / Flop (Ctrl+8 / Ctrl+9); and Transform (zoom, pan, rotate).

Holding Alt while panning or zooming applies the transformation to all viewports simultaneously (gang mode). Hold Shift while zooming for 10× finer control. Reset one viewport with Ctrl+R, all viewports with Ctrl+Alt+R.

The text overlay (T) cycles through: off → basic info (frame, time, FPS, filename, resolution) → basic + DPX/EXR/EXIF metadata. Press Alt+T to toggle all viewports. Right-click with Ctrl held to activate the color picker (display pixel value under cursor).

Channels & comparison

Isolate the R, G, B, or A channels with R / G / B / A, or click the RGB button in the Control Bar to cycle. Load multiple sequences into separate tracks and assign them to different viewports for side-by-side comparison. The Difference Matte FX and the Split FX (adjustable wipe) are available in the FX Stack for advanced comparison work.

Menus

File — Load Manager (Ctrl+L), Playlist Manager (Ctrl+P), Save/Open Session (Ctrl+S / Ctrl+O), Save Chat Log, Preferences, Quit (Ctrl+Q).

View — Layout, Zoom Filtering (Point / Bilinear), Aspect Bars Opacity, Fit to viewport (F / Alt+F), Flip/Flop, Reset transforms, Histogram (Ctrl+H), Fullscreen (Ctrl+F), Hide Controls (Ctrl+Alt+F).

Dialogs — FX Stack Manager (F2), FX Manager (F3), LUT Manager (F4), Remote Session Manager (F5), Render Manager (F6).

Help — User Manual (F1), toggle on-screen help (H), System Requirements check, About.

Playlists

A Playlist Item is a complete application snapshot: loaded tracks with their parameters, viewport layout, playback settings, and FX stacks. Use playlists to jump instantly between different shot setups.

Open the Playlist Window with Ctrl+P. Add items from the Load Window's Add to Playlist button, from the Main Window button, or by dragging a sequence frame into the Playlist Window. Double-click or press Enter to recall an item. Reorder with Shift+Up / Shift+Down. Save to a .jpl file; loading multiple playlists appends their items. Only sequences loaded through the Playlist Window are automatically shared in remote sessions.

Remote sessions

A Remote Session links two or more JefeCheck instances over a LAN or the Internet. No image data is transmitted — each participant loads their own local copy of the sequences. All playback, scrubbing, FX changes, and viewport transforms are mirrored in real time.

To host: open the Remote Session Manager (F5), fill in a server name, port (32000+ recommended), and optional password, then click Start. The Server IP box shows the address to share with participants.

To join: enter the server IP, port, password (if any), and a nickname, then click Connect. The status bar turns green when online.

Chat: press Y to enter chat mode, type a message, press Enter to send. Navigate history with ↑ / ↓. Press Escape to exit chat mode. Toggle incoming message display outside chat mode with Ctrl+Y. Save the full chat log via File > Save Chat Log.

Remote Pointers: right-click and drag on the viewport to show your cursor (with your nickname) to all participants. JefeCheck compensates for different scales and monitor resolutions so pointers refer to the same pixel on the image regardless of proxy scale.

Color & FX

JefeCheck processes images non-destructively in two stages: Load-Time Modifications (baked into the track — scale, crop, bit depth) and Real-Time Modifications (applied by the GPU as frames are drawn — color corrections, LUTs, GLSL FX). Nothing touches source files on disk.

Color correction controls

The Control Bar exposes six real-time adjustments per viewport, applied in this order: LUT → Exposure → Gamma → Brightness → Saturation → Contrast. Hold a key and drag on the viewport to adjust interactively:

  • W + drag — Gamma
  • E + drag — Exposure
  • Q + drag — Brightness
  • D + drag — Contrast
  • S + drag — Saturation

Reset the active viewport's corrections with Shift+R, all viewports with Shift+Alt+R. Save up to 5 color-correction favorites with Ctrl+Shift+1–5; recall with Shift+1–5.

LUT Manager

Open the LUT Manager with F4 or Dialogs > LUT Manager. Click Browse to select one or more LUT files. Check Auto-Load next to each LUT to have it load automatically on next launch. Scroll through loaded LUTs in the Control Bar by holding L and pressing Up / Down (L+Up / L+Down).

The LUT Manager can visualize any loaded LUT: 1D LUTs plot as an X/Y curve (input on X, output on Y); 3D LUTs render as a color cube in the viewport — a deformed cube indicates a color transformation, a straight line means desaturation. A default LUT for all viewports can be set in the LUT Manager or overridden with the environment variable JEFECHECK_DEFAULT_LUT.

Supported LUT formats

Format Type Notes
.cub3D — Truelight cubeTested at 16³ and 32³; generated from Nuke's CMS node
.tga (JefeCheck)3D — native format64×64 px image encoding a 16³ LUT; process the included UnitCube.tga through any pipeline and save as TGA — not currently loadable; image-based LUT loading is disabled pending OpenImageIO support
.tga (Nuke CMS)3D — Nuke export448×448 px TGA from a Nuke CMS node at size 16; render with linear color space — not currently loadable; image-based LUT loading is disabled pending OpenImageIO support
.lut1D — native formatPlain text; header + entry count + normalized float values (0.0–1.0 per entry)

The working LUT formats today are Truelight .cub (3D) and JefeCheck .lut (1D); .tga 3D LUTs are not yet supported by the current OpenImageIO backend.

Apply a LUT at launch:

$ jefecheck shot.1001.exr --lut LogToLinToSRGB.lut
# --lut takes the LUT filename (not the full path); must be in the LUT path or set to auto-load

FX Manager, FX Stack & FX Control

JefeCheck uses a GLSL plug-in system for real-time effects. The workflow:

  1. Load FX plug-ins — open the FX Manager (F3), click Browse, select one or more .jfx files. Check Auto-Load to persist across launches.
  2. Apply to a viewport — open the FX Stack Manager (F2), click the target viewport, then choose an FX from the Available FX menu. FXs stack in order — each FX's output feeds the next. Different viewports carry independent FX stacks.
  3. Adjust parameters — each FX shows its own controls. Click-drag to change numeric values (left-click = fine, middle = 10×, right = 100×). Toggle On/Off to compare without removing the FX.

Save and recall complete stacks (.fxs files) from the FX Control Window menu. Five FX Favorites: save with Ctrl+Shift+F1–F5, recall with Shift+F1–F5, append with Ctrl+F1–F5. Reorder FXs in the stack with the Up/Down buttons on each FX entry.

Included FX categories

  • Color — 1D LUT, 3D LUT, Brightness/Contrast/Saturation, Gamma, Primary Color Correction (per-channel BCS).
  • Comp (compositing) — Chroma Key (Blue/Green screen with matte preview), Difference Matte (abs(A−B)×multiplier), Inside, Mix (blend by amount), Over (with premult option), Split (wipe with adjustable slope and softness), Subtract.
  • Special — Anaglyph Color Stereo (left/right tracks → cyan/red anaglyph), OpenEXR (gamma/exposure for HDR half-float images), Fields (interlace line simulation).
  • Transitions — Fade (animated cross-fade between two tracks, configurable start frame and length), Radial (growing radial matte transition with edge softness).
  • Fun — miscellaneous creative effects available in the Fun category of the FX Manager.

Authoring custom FX plug-ins (.jfx)

Each FX is three files placed in the FX folder:

  • plugin.jfx — XML descriptor: FX name, menu path (menuName="Comp/Mix"), author, widget definitions, and shader filenames.
  • plugin.frag — GLSL fragment shader. Declare uniform variables matching the varName attributes in the .jfx. Write result to gl_FragColor. Textures use sampler2DRect (pixel-space coordinates, not normalized 0–1).
  • plugin.vert — GLSL vertex shader. Most FXs share the standard fixed.vert, which passes four texture coordinate sets to the fragment shader.

Widget types available in the .jfx descriptor: float, bool, texture (track A/B/C/D or previous FX output), cube (3D LUT), lut (1D LUT), choice, newline, spacer.

The application also injects these uniform variables — declare them in your shader if you need them: currentFrame (float), timeStep (ms since last draw), targetFPS, and texture size vectors texCoord0–texCoord4. Study MIX.jfx / MIX.frag and OVER.jfx in the FX folder as starting points.

Pipeline integration — command-line flags

The first sequence argument goes into Track A, the second into Track B, and so on. Track options (-f, -t, -s) and viewport options (-x, -l) apply in the order they appear relative to others of the same type.

Flag Long form Description
-h--helpShow help message
-f--fromStart loading from this frame (track option)
-t--toStop loading at this frame (track option)
-s--scaleLoad at this scale percentage (100, 50, 25…) (track option)
-r--frameRateTarget playback frame rate (global option)
-x--fxFX Stack file (.fxs) to apply to a viewport (viewport option)
-l--lutLUT filename to apply to a viewport (viewport option)
# Load two sequences, frames 12–45 for A and 520–530 for B, at 24 fps
$ jefecheck seq1.0001.dpx -f 12 -t 45 seq2.0001.dpx -f 520 -t 530 -r 24
# Load A at full res, B at 50% proxy, apply a LUT to viewport 1
$ jefecheck seq1.0001.exr -s 100 seq2.0001.exr -s 50 -l show_rec709.cub
# Use 4-digit hash padding; range must be explicit
$ jefecheck seq1.####.dpx -f 12 -t 45

Build from Source

JefeCheck is free software under GPL v2. It uses CMake across all platforms targeting C++20. If you prefer not to build, download pre-built binaries from the GitHub Releases page.

macOS

Tested on Apple Silicon (ARM64). OpenGL runs via Apple's Metal translation layer — deprecated by Apple but fully functional for JefeCheck. Retina displays are supported automatically.

# Install dependencies via Homebrew
$ brew install fltk openimageio openexr curl zlib cmake freetype
# Clone and build
$ git clone https://github.com/danielgollas/jefecheck.git
$ cd jefecheck
$ cmake -B build && cmake --build build

Linux (Ubuntu 24.04)

# Install dependencies
$ sudo apt install cmake build-essential \
libfltk1.3-dev libopenimageio-dev openimageio-tools \
libopenexr-dev libimath-dev libilmbase-dev libcurl4-openssl-dev zlib1g-dev \
freeglut3-dev libgl-dev libglu1-mesa-dev \
libx11-dev libxext-dev libxft-dev libxinerama-dev \
libxcursor-dev libxrender-dev libxfixes-dev \
libopencv-dev libfreetype6-dev
# Clone and build
$ git clone https://github.com/danielgollas/jefecheck.git && cd jefecheck
$ cmake -B build && cmake --build build -j$(nproc)
# Or use the convenience script
$ bash build_linux.sh

Windows (MSYS2 / MinGW)

Install MSYS2, then from the MinGW 64-bit shell:

# Install dependencies via pacman
$ pacman -S --noconfirm \
mingw-w64-x86_64-cmake mingw-w64-x86_64-toolchain \
mingw-w64-x86_64-fltk mingw-w64-x86_64-openimageio \
mingw-w64-x86_64-openexr mingw-w64-x86_64-imath \
mingw-w64-x86_64-curl mingw-w64-x86_64-zlib \
mingw-w64-x86_64-freeglut mingw-w64-x86_64-freetype \
mingw-w64-x86_64-fmt
# Clone and build
$ git clone https://github.com/danielgollas/jefecheck.git && cd jefecheck
$ cmake -B build -G "MinGW Makefiles" && cmake --build build

The Windows build uses -fpermissive for FLTK callback casts. CI builds are automated via GitHub Actions — see .github/workflows/build.yml.

Runtime resources

JefeCheck looks for FX plug-ins and fonts relative to the binary. For development builds, create symlinks from the source tree:

$ ln -sf $(pwd)/src/FX FX
$ ln -sf $(pwd)/src/fonts fonts

Release builds package src/FX/ and src/fonts/ alongside the binary automatically.

CI & pre-built binaries

GitHub Actions builds on all three platforms for every push to main. Tagged v* releases publish downloadable archives on the Releases page:
