FFmpeg
======

JefeCheck uses FFmpeg (https://ffmpeg.org) in two separate ways.

1. Linked libraries (movie reading and sound)
   JefeCheck links libavformat, libavcodec, libavutil, libswresample and
   libswscale to read .mov/.mp4 movies and their audio. Release builds take
   these libraries from the platform package, not from the static build in
   item 2:
     - macOS:   Homebrew "ffmpeg" (libraries bundled into the app)
     - Windows: MSYS2 "mingw-w64-x86_64-ffmpeg" (DLLs shipped with the app)
     - Linux:   the distribution's libav* packages (the Linux package
                depends on them; they are not bundled)
   These FFmpeg builds are GPL builds (--enable-version3), so distributed
   JefeCheck binaries are effectively under the GNU GPL version 3.
   FFmpeg is licensed under the GPL version 2 or later; JefeCheck is
   distributed under the GPL version 2 or (at your option) any later
   version.

2. Bundled "ffmpeg" command-line program (video export only)
   JefeCheck runs a separate static ffmpeg executable as a subprocess to
   encode rendered image sequences into H.264 / H.265 / ProRes files. It
   is a GPL build obtained from:
     https://github.com/eugeneware/ffmpeg-static  (release b6.1.1)
   You may replace it with your own ffmpeg build, or point JefeCheck at a
   different one via Preferences -> Render -> FFmpeg path or the
   JEFECHECK_FFMPEG environment variable.

Version and configure line of the linked libraries
   Each release package records them, at packaging time, in the file
   ffmpeg-libs-VERSION.txt next to this notice:
     - macOS:   JefeCheck.app/Contents/Resources/ffmpeg-libs-VERSION.txt
                (output of the Homebrew package's `ffmpeg -version`, which
                prints the version, the configure line and every libav*
                version, plus the list of dylibs bundled in
                Contents/Frameworks/)
     - Windows: ffmpeg-libs-VERSION.txt next to jefecheck.exe (output of
                MSYS2's `ffmpeg.exe -version`)
     - Linux:   ffmpeg-libs-VERSION.txt in the package directory (the
                distribution package versions and libav* versions the
                build linked against; the libraries themselves come from
                your distribution, so `ffmpeg -version` there, or the
                distribution's source package, gives their configure line)

Corresponding source
   - FFmpeg: the release tarball for the matching version at
     https://ffmpeg.org/download.html , plus the package recipe
     (Homebrew formula "ffmpeg", MSYS2 PKGBUILD "mingw-w64-ffmpeg", or
     the distribution's source package). For the static CLI binary in
     item 2, see the ffmpeg-static release above and https://ffmpeg.org .
   - JefeCheck: https://github.com/danielgollas/jefecheck
